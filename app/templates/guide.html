{% if lang == 'ja' %}3. SRS 音声通信{% else %}3. SRS Voice{% endif %}

{% if lang == 'ja' %}

SRS は陣営別・周波数別のボイスチャットです。DCS 本体の音声機能は使いません。 サーバーと同じ v2.3.4 系 を入れてください (バージョンが違うと接続できません)。

  1. SRS クライアントを起動 (DCS と同じ PC で OK)
  2. Server Address に下表の値を入力して接続
  3. 機体に乗ると機載無線と自動同期 (Auto Select Controls = ON 推奨)
{% else %}

SRS is per-coalition, per-frequency voice chat. It does not use DCS's built-in voice. Install the same v2.3.4 series as the servers (different versions cannot connect).

  1. Start the SRS client (the same PC as DCS is fine)
  2. Enter the address from the table below in Server Address and connect
  3. Once in an aircraft it auto-syncs with the on-board radio (Auto Select Controls = ON recommended)
{% endif %}

5. DCS Olympus

{% if lang == 'ja' %}

ブラウザからユニットを配置・操作できる RTS 風の管制インターフェースです。 DCS を起動していなくても、ブラウザだけで参加できます。

  • 地図上にユニットを スポーン (航空機・地上部隊・艦艇)
  • 既存ユニットへの 指示 (移動・攻撃・護衛・給油 など)
  • 編隊の グループ化、経路設定、ROE 変更
  • 味方支援のシナリオを飛行中の仲間に合わせてその場で作る、といった使い方ができます
{% else %}

An RTS-style control interface for placing and commanding units from the browser. You can take part entirely in the browser, without launching DCS.

  • Spawn units on the map (aircraft, ground forces, ships)
  • Task existing units (move, attack, escort, refuel, etc.)
  • Group formations, set routes, change ROE
  • e.g. build friendly-support scenarios on the spot around whoever is currently flying
{% endif %}

{% if lang == 'ja' %}無線 (SRS 連携){% else %}Radio (SRS integration){% endif %}

{% if lang == 'ja' %}

Olympus から SRS の無線につなぐことができます。 画面上部の スピーカーのアイコンで音声機能を有効にしてください。 初回はブラウザがマイクの使用許可を求めます。

  • 接続先はサーバーごとに自動で選ばれます (Server 1 なら Server 1 の SRS)
  • Chrome を推奨します (Olympus 公式の推奨ブラウザ)
{% else %}

Olympus can connect to the SRS radio. Enable the audio feature via the speaker icon at the top of the screen. The browser will ask for microphone permission the first time.

  • The SRS endpoint is chosen automatically per server (Server 1 connects to Server 1's SRS)
  • Chrome is recommended (the officially supported browser for Olympus)
{% endif %} {% if lang == 'ja' %}

この機能は導入したばかりです。 Olympus が SRS に接続し、SRS 側のクライアント一覧に出るところまでは 接続までは確認できていますが、実際の送話・受話は まだ十分に試せていません。うまくいかない場合や気づいた点があれば Discord で教えていただけると助かります。 無線が確実に必要な場面では、従来どおり SRS クライアントをお使いください。

{% else %}

This feature is brand new. We have confirmed that Olympus connects to SRS and shows up in the SRS client list, but actual transmitting / receiving has not been thoroughly tested yet. If it doesn't work for you, or you notice anything odd, a report on Discord is appreciated. For situations where the radio absolutely must work, keep using the regular SRS client.

{% endif %} {% if lang == 'ja' %}

The audio feature only works over HTTPS, because browsers only grant microphone access on secure connections. Use the https:// URLs from the table above.

{% if lang == 'ja' %}7. Discord から使う{% else %}7. Using Discord{% endif %}

{% if lang == 'ja' %}7.1 最初にやること — アカウント連動{% else %}7.1 First step — account linking{% endif %}

{% if lang == 'ja' %}

DCS 内の名前と Discord を紐付けます。 これをしないと録画検索や統計が自分に紐付きません。

  1. Discord の任意のチャンネルで /linkme を実行
  2. 表示された 4 桁 TOKEN を DCS 内チャット (Enter キー → 入力欄) に貼り付け
  3. bot から DM で「Linked successfully」が届けば完了

DCS 内から始めることもできます。チャットで .linkme と入力してください。

{% else %}

Link your in-game DCS name to Discord. Without this, replays and stats won't be attributed to you.

  1. Run /linkme in any Discord channel
  2. Paste the 4-digit TOKEN it shows into in-game DCS chat (press Enter → type it in)
  3. When the bot DMs you "Linked successfully", you're done

You can also start from inside DCS: type .linkme in chat.

{% endif %}
