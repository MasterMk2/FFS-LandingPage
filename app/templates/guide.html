Player Guide

FFS DCS サーバーへの参加方法、SRS / LotATC / Tacview / Olympus の設定、 ブラウザで使えるツール、Discord bot の使い方をまとめたプレイヤー向けガイドです。

最終更新: 2026-09-03

はじめに DCS に接続 SRS 音声 LotATC / Tacview Olympus ブラウザツール Discord 困ったとき

1. はじめに

FFS は DCS World の専用サーバーを 3 台 運用しているコミュニティです。 無料機体だけでも参加できます。まずは Server 1 に入ってみてください。

ソフト必要度用途
DCS World
(Steam / ED Standalone)		 必須 本体。無料機体のみでも参加可
SRS クライアント 強く推奨 無線通信。サーバーは v2.3.4 系
Discord アカウント 推奨 統計連動・サーバー操作・告知の受け取り
Tacview 任意 リアルタイム観戦・録画解析
LotATC 任意 GCI / 管制として参加する場合

DCS の Multiplayer Name は後で Discord と紐付けます (8. Discord)。決めてから入るとスムーズです。

2. DCS に接続する

DCS を起動 → Multiplayer → サーバー一覧から選びます。 稼働状況は Status ページ でリアルタイムに確認できます。

サーバーDCS 内の表示名用途
Server 1FFS open alpha 1常設 — いつでも飛べるメイン枠
Server 2FFS open alpha 2自由 — ミッションを入れ替えて使える枠
Server 3FFS open alpha 3イベント / CO-OP — 非開催時は自由に使用可

Server 2 / 3 は必要なときだけ起動する運用です。停止中でも Discord の /server startup で誰でも起動できます (8.3)。

一覧に出ないとき — Direct Connect

サーバーリストが混雑して見つからない場合は、IP とポートを直接指定してください。 ゲーム系クライアントは IP 直打ち を推奨します (ホスト名だと DCS 側の解決に失敗することがあるため)。

サーバーホストポート

3. SRS 音声通信

SRS は陣営別・周波数別のボイスチャットです。DCS 本体の音声機能は使いません。 サーバーと同じ v2.3.4 系 を入れてください (バージョンが違うと接続できません)。

  1. SRS クライアントを起動 (DCS と同じ PC で OK)
  2. Server Address に下表の値を入力して接続
  3. 機体に乗ると機載無線と自動同期 (Auto Select Controls = ON 推奨)
サーバーアドレスポート
Server 1111.237.107.6418111
Server 2111.237.107.6418112
Server 3111.237.107.6418113

Tacview — リアルタイム観戦・録画

Tacview Advanced をお持ちなら、live で戦況を見ながら録画もできます。 Tacview の Record a Telemetry Stream に 111.237.107.64:1813x を指定してください。

5. DCS Olympus

ブラウザからユニットを配置・操作できる RTS 風の管制インターフェースです。 DCS を起動していなくても、ブラウザだけで参加できます。

  • 地図上にユニットを スポーン (航空機・地上部隊・艦艇)
  • 既存ユニットへの 指示 (移動・攻撃・護衛・給油 など)
  • 編隊の グループ化、経路設定、ROE 変更
  • 味方支援のシナリオを飛行中の仲間に合わせてその場で作る、といった使い方ができます
サーバー接続先
Server 1freedomflight.jp/olympus1/
Server 2freedomflight.jp/olympus2/
Server 3freedomflight.jp/olympus3/

使いはじめかた

  1. 入りたいサーバーの URL を開きます (上の表)。
  2. Role を選びます。
    Game master = 全陣営を操作できる進行役 / Blue commander・Red commander = 各陣営のみ
  3. Password を入れて Login。 パスワードは Discord の #status-serverN チャンネル (bot が自動更新している稼働状況の投稿) の DCS Olympus 欄に、接続先 URL と一緒に掲示しています (GameMaster / Blue・Red Commander の 3 つ)。 現在 Olympus が動いているのは Server 1 なので #status-server1 をご覧ください。

ブックマークするときは 末尾のスラッシュまで 含めてください (/olympus1/)。スラッシュ無しでも自動で補われます。

無線 (SRS 連携)

Olympus から SRS の無線につなぐことができます。 画面上部の スピーカーのアイコンで音声機能を有効にしてください。 初回はブラウザがマイクの使用許可を求めます。

  • 接続先はサーバーごとに自動で選ばれます (Server 1 なら Server 1 の SRS)
  • Chrome を推奨します (Olympus 公式の推奨ブラウザ)

この機能は導入したばかりです。 Olympus が SRS に接続し、SRS 側のクライアント一覧に出るところまでは 接続までは確認できていますが、実際の送話・受話は まだ十分に試せていません。うまくいかない場合や気づいた点があれば Discord で教えていただけると助かります。 無線が確実に必要な場面では、従来どおり SRS クライアントをお使いください。

音声機能は HTTPS 接続でのみ動作します。ブラウザがマイクへの アクセスを安全な接続でしか許可しないためです。上の表の https:// の URL をお使いください。

6. ブラウザで使えるツール

DCS を持っていなくても、ブラウザだけで戦況を追ったり管制ができます。

ツールできること
Status 稼働状況・ミッション・気象・接続情報・サーバー負荷を 15 秒毎に更新
Sneaker 飛行中の機体を 2D マップにリアルタイム表示。AWACS 役や地上指揮に
Web GCA ブラウザ管制卓。GCA (PAR) の進入誘導、GCI、TWR。滑走路データは DCS から自動取得
Landing Teacher 着陸・着艦を自動検出して採点。空母は LSO グレーディング、陸上は A〜E
現在 Server 1 のみ対応
Lardoon 自動録画された Tacview (.acmi) の一覧・検索・ダウンロード。単一フライトへの trim も可
Replays DCS のリプレイ (.trk) をダウンロード。DCS の File → Open で再生
Leaderboard 過去 30 日の飛行時間・撃墜・K/D のランキング
Known Issues 既知の不具合と対処状況

7. Discord から使う

7.1 最初にやること — アカウント連動

DCS 内の名前と Discord を紐付けます。 これをしないと録画検索や統計が自分に紐付きません。

  1. Discord の任意のチャンネルで /linkme を実行
  2. 表示された 4 桁 TOKEN を DCS 内チャット (Enter キー → 入力欄) に貼り付け
  3. bot から DM で「Linked successfully」が届けば完了

DCS 内から始めることもできます。チャットで .linkme と入力してください。

7.2 サーバーの様子を見る

コマンド / チャンネル内容
/server list全サーバーの稼働状況・ミッション・人数
/serverloadCPU / RAM / FPS / ネットワークのグラフ。重さの切り分けに
/serverstats1 か月スパンの集計 (プレイヤー数推移など)
#status-server1/2/3稼働状況と参加者を bot が自動更新。末尾に直近 24h の負荷グラフ
#chat-server1/2/3DCS 内チャットと Discord の双方向ブリッジ
#events撃墜・墜落・着艦グレード・爆撃命中などの通知

7.3 ミッション / サーバーを操作する

Open α では ほぼ全てのコマンドを @everyone に開放しています。 遠慮なく使ってください。

コマンド動作
/mission loadミッションを切り替え
/mission restart / rotateリスタート / 次のミッションへ
/mission pause / unpause一時停止 / 再開
/mission modify天候・時刻などのプリセット変更
/server startup停止中のサーバーを起動 (Server 2 / 3 を使いたいとき)
/server stop / restart / shutdownミッション停止 / 再起動 / サーバー終了
/server lock / unlock新規参加のブロック / 解除
/server passwordスロットパスワードの変更

/server shutdown や /server password は 他のプレイヤーに直接影響します。人が乗っていないか確認してから使ってください。

ミッションファイルを追加する

作った .miz は、対象サーバーの #admin-serverN チャンネルに ドラッグ & ドロップするだけで追加できます。 アップロード後そのまま /mission load で切り替えられます。

同名ファイルは上書きされます。残したいものは名前を変えてから投げてください。

8. 困ったとき

症状対処
サーバー一覧に出ない Direct Connect (111.237.107.64:1810x) で接続。ルーター側で UDP が塞がれている可能性もあります
Server 2 / 3 に入れない 停止中です。Discord で /server startup を実行すれば起動します
SRS が version mismatch サーバーは v2.3.4 系です。同じ系列を入れ直してください
bot が反応しない /linkme が未実行の可能性。再起動直後はコマンド同期に数分かかります
Olympus にログインできない Role とパスワードの組み合わせをご確認ください。パスワードは Discord の #status-server1 の稼働状況投稿 (DCS Olympus 欄) に掲示しています (5. DCS Olympus)
Sneaker が disconnected ミッション上にユニットが 0 機の状態です。進行すれば自動で復帰します
Lardoon に新しい録画が出ない 最大 30 秒ほど遅延します。それ以上なら Discord で報告してください
