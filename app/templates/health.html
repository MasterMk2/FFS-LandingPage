{% if lang == 'ja' %}解像度と鮮度{% else %}Resolution and freshness{% endif %}

{% if lang == 'ja' %}

Fitbit Charge 6 が記録した粒度をそのまま保存しているので、心拍は 中央値 2-3 秒間隔 (1 日あたり約 36,000 点) で取り出せます。

ただしリアルタイムではありません。 時計 → スマートフォン → Google クラウドの同期が挟まるため、最新の点でも 数分〜十数分前のものです。時計がスマートフォンと離れているとき (就寝中など) は数時間空くこともあります。この遅延はデータ提供元の都合で、 こちら側では短縮できません。

そのため minutes=5 のような短い窓を指定すると count が 0 になることが普通にあります。 「今の値」が欲しい場合は /latest を使い、 age_seconds を見て古さを判断してください。 minutes は 30 以上を推奨します。

{% else %}

Data is stored at the granularity recorded by the Fitbit Charge 6, so heart rate can be retrieved at a median interval of 2–3 seconds (roughly 36,000 points per day).

However, it is not real-time. The watch syncs via the phone to Google's cloud, so even the newest point is typically several to a dozen-plus minutes old. When the watch is away from the phone (e.g. while sleeping) gaps of several hours can occur. This lag comes from the data provider and cannot be shortened on our side.

For that reason, short windows like minutes=5 can legitimately return count = 0. If you need "the current value", use /latest and judge staleness from age_seconds. minutes of 30 or more is recommended.

{% endif %}

{% if lang == 'ja' %}制限{% else %}Limits{% endif %}

    {% if lang == 'ja' %}
  • IP あたり 60 リクエスト / 分。超えると 429 と Retry-After を返します。
  • 1 回のリクエストで最大 24 時間分 / 50,000 点。
  • 公開しているのは 心拍のみです (/types で確認できます)。 他のデータ型は 404 になります。
  • 読み取り専用です。書き込み系のメソッドはありません。
    • {% else %}
  • 60 requests / minute per IP. Beyond that you get 429 plus a Retry-After header.
  • Up to 24 hours / 50,000 points per request.
  • Only heart rate is published (check with /types). Other data types return 404.
  • Read-only — no write methods exist.
    • {% endif %}

{% if lang == 'ja' %}使用例{% else %}Usage examples{% endif %}

{% raw %} 
// Browser (CORS enabled)
const r = await fetch(
  'https://freedomflight.jp/health/v2/api/public/series?type=heart-rate&minutes=60');
const { points, unit } = await r.json();
console.log(points.length, unit);   // 1433 'bpm'
# Python
import urllib.request, json
BASE = "https://freedomflight.jp/health/v2/api/public"

with urllib.request.urlopen(f"{BASE}/latest?type=heart-rate") as r:
    d = json.load(r)
print(f"{d['value']:.0f} {d['unit']} ({d['age_seconds'] // 60} min ago)")

# Last 6 hours decimated to 5-minute granularity
url = f"{BASE}/series?type=heart-rate&minutes=360&max_points=72"
with urllib.request.urlopen(url) as r:
    s = json.load(r)
print(s["count"], "points", "decimated" if s["truncated"] else "as recorded")
