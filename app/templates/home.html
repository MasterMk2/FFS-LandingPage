Tools & Services

Sneaker — Live Map

{% if lang == 'ja' %}

飛行中の機体位置を 2D マップ上でリアルタイム表示する戦況モニタ。 Tacview テレメトリをブラウザで受信し、味方・敵・中立の動きを追跡できます。 Discord で地上指揮や AWACS 役をしたいときに便利。

{% else %}

A real-time situation monitor plotting airborne aircraft on a 2D map. It receives Tacview telemetry in the browser and tracks friendly, enemy and neutral movement. Handy for ground command or playing AWACS over Discord.

{% endif %} {{ t('cta_open_sneaker') }}

{{ t('home_card_gca_title') }}

{% if lang == 'ja' %}

ブラウザで動く地上管制卓。Tacview のリアルタイムテレメトリから 進入中の機体を拾い、GCA (PAR) の方位・降下スコープと トークダウン ("5 miles from touchdown, on course, on glidepath") を自動生成します。 迎撃管制の GCI、飛行場管制の TWR も同じ画面から。 滑走路データは DCS 本体から取得しているので、マップが変わっても手直し不要です。

{% else %}

A ground ATC console that runs in the browser. It picks up inbound traffic from Tacview's real-time telemetry and auto-generates the azimuth / elevation scopes and talkdown of GCA (PAR) ("5 miles from touchdown, on course, on glidepath"). Interception control (GCI) and aerodrome control (TWR) work from the same screen. Runway data is taken from the DCS installation itself, so no rework is needed when the map changes.

{% endif %} {{ t('cta_open_gca') }}

{{ t('home_card_olympus_title') }}

{% if lang == 'ja' %}

ブラウザからユニットを配置・操作できる RTS 風インターフェース。 航空機・地上部隊・艦艇をその場でスポーンし、移動や攻撃を指示できます。 DCS を起動していなくても参加でき、飛んでいる仲間に合わせてシナリオを作る、 味方支援を足す、といった遊び方ができます。 サーバーごとに URL が分かれています。ログインに必要なパスワードは Discord の #status-server1 (稼働状況の投稿、DCS Olympus 欄) に掲示中。

{% else %}

An RTS-style interface for placing and commanding units from the browser. Spawn aircraft, ground forces and ships on the spot, then task them to move or attack. You can join in without launching DCS — build scenarios around whoever is flying, or add friendly support on the fly. Each server has its own URL. Login passwords are posted on Discord's #status-server1 (the auto-updated status post, DCS Olympus section).

{% endif %} {{ t('cta_olympus_how') }}

{{ t('home_card_lt_title') }}

{% if lang == 'ja' %}

Tacview のリアルタイムテレメトリから着陸・着艦を自動検出し、 空母着艦は米海軍式 LSO グレーディング (OK / OK- / (OK) / CUT ほか)、 陸上着陸は簡易採点 (A〜E) で振り返えます。 履歴ダッシュボードと GCA スコープ風の進入軌跡ビューをブラウザで確認可能。 現時点は server1 のみ対応。

{% else %}

Auto-detects landings and carrier traps from Tacview's real-time telemetry: carrier traps are graded with the US Navy LSO scale (OK / OK- / (OK) / CUT and more), field landings with a simple A–E score. Reviewable in the browser via a history dashboard and a GCA-style approach-path view. Server 1 only for now.

{% endif %} {{ t('cta_open_lt') }}

Lardoon — Tacview Archive

{% if lang == 'ja' %}

各サーバで自動録画された Tacview (.acmi) を一覧・検索・ダウンロードできる Web アーカイブ。 単一フライトへの trim 機能で必要な部分だけ小さく落とせます。再生は手元の Tacview デスクトップアプリで。

{% else %}

A web archive that lists, searches and serves the Tacview (.acmi) recordings captured automatically on each server. Trim to a single flight to download just the part you need. Playback happens in your local Tacview desktop app.

{% endif %} {{ t('cta_open_lardoon') }}

{{ t('home_card_replays_title') }}

{% if lang == 'ja' %}

各サーバで自動保存された DCS のリプレイファイル (.trk) を一覧・ダウンロード。 DCS World の File → Open で再生でき、デブリーフィング / AAR / 機動検証に使えます。

{% else %}

Lists and serves the DCS replay files (.trk) auto-saved on each server. Replay them via File → Open in DCS World — useful for debriefs, AAR and manoeuvre checks.

{% endif %} {{ t('cta_view_replays') }}
