Tools & Services

Sneaker — Live Map

飛行中の機体位置を 2D マップ上でリアルタイム表示する戦況モニタ。 Tacview テレメトリをブラウザで受信し、味方・敵・中立の動きを追跡できます。 Discord で地上指揮や AWACS 役をしたいときに便利。

sneaker.freedomflight.jp を開く ↗

Web GCA — 管制コンソール

ブラウザで動く地上管制卓。Tacview のリアルタイムテレメトリから 進入中の機体を拾い、GCA (PAR) の方位・降下スコープと トークダウン ("5 miles from touchdown, on course, on glidepath") を自動生成します。 迎撃管制の GCI、飛行場管制の TWR も同じ画面から。 滑走路データは DCS 本体から取得しているので、マップが変わっても手直し不要です。

管制卓を開く ↗

DCS Olympus — ブラウザ管制 / ユニット配置

ブラウザからユニットを配置・操作できる RTS 風インターフェース。 航空機・地上部隊・艦艇をその場でスポーンし、移動や攻撃を指示できます。 DCS を起動していなくても参加でき、飛んでいる仲間に合わせてシナリオを作る、 味方支援を足す、といった遊び方ができます。 サーバーごとに URL が分かれています。ログインに必要なパスワードは Discord の #status-server1 (稼働状況の投稿、DCS Olympus 欄) に掲示中。

使い方を見る →

Landing Teacher — 着陸/着艦レビュー

Tacview のリアルタイムテレメトリから着陸・着艦を自動検出し、 空母着艦は米海軍式 LSO グレーディング (OK / OK- / (OK) / CUT ほか)、 陸上着陸は簡易採点 (A〜E) で振り返れます。 履歴ダッシュボードと GCA スコープ風の進入軌跡ビューをブラウザで確認可能。 現時点は server1 のみ対応。

Landing Teacher を開く ↗

Lardoon — Tacview Archive

各サーバで自動録画された Tacview (.acmi) を一覧・検索・ダウンロードできる Web アーカイブ。 単一フライトへの trim 機能で必要な部分だけ小さく落とせます。再生は手元の Tacview デスクトップアプリで。

lardoon.freedomflight.jp を開く ↗

リプレイダウンロード

各サーバで自動保存された DCS のリプレイファイル (.trk) を一覧・ダウンロード。 DCS World の File → Open で再生でき、デブリーフィング / AAR / 機動検証に使えます。
