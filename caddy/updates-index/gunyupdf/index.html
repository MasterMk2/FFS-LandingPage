GUNYUPDF

本をスキャン・撮影した PDF の、綴じ部の湾曲・ページの傾き・影を補正して、読みやすい PDF にするアプリです。

ダウンロードページへ

ダウンロードページを開くとパス（ID とパスワード）を尋ねられます。パスは配布元から受け取ってください。

できること

  • 湾曲の補正: 綴じ部の近くで曲がった文字の行を平らに直す
  • 傾きの補正: ページ全体の回転のずれを直す
  • 台形の補正: カメラで撮った写真の遠近のゆがみを直す
  • 影・明るさの補正: 綴じ部の影、照明のむら、紙の黄ばみを取り、白い背景に近づける
  • 横書きと縦書きの本の両方に対応
  • 画面で操作する GUI と、まとめて処理できるコマンド（CLI）の両方があります

対象外

  • 文字認識（OCR）そのもの。補正した PDF は OCR しやすくなります
  • 文字の情報を持つ PDF（電子書籍など）。画像のスキャン PDF が対象です

動作環境と配布の形

OSWindows（64 ビット）
配布の形インストーラーと、インストール不要のポータブル版（ZIP）

更新のしかた

入れたあとは、アプリの更新の確認から新しい版に更新できます。初回だけ同じパスを入力します。更新情報は配布元の電子署名を確かめてから使います。
