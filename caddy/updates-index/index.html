ダウンロード

自作の Windows 向けアプリです。製品名から紹介を、右のリンクからダウンロードページを開けます。

  • EddiePDF オフラインで動く多機能 PDF 編集ソフト ダウンロード
  • GUNYUPDF 書籍スキャン PDF の湾曲・傾き・影を補正するアプリ ダウンロード
  • ALLOCR 日本語文書をクラウドに送らずにテキスト化する OCR アプリ ダウンロード
  • Transinglater オフラインで動く日英翻訳ソフト ダウンロード
  • IshikawADE やりたいことを開発タスクに整理し、計画と PR 本文案をつくるアプリ ダウンロード
  • DCS Mission Studio公開 DCS のミッション（.miz）を、原本を残して編集するツール 配布ページ

パスについて

  • DCS Mission Studio 以外のダウンロードページを開くと、ブラウザが ID とパスワード（パス）を尋ねます。パスは配布元から受け取ったものを入力してください。
  • 製品ごとのパスはその製品だけ、開発協力者用のパス（ID が dev- で始まるもの）はすべての製品で使えます。
  • 入れたあとの更新はアプリの［更新を確認...］からできます。アプリでも同じパスを一度入力します。
  • 配信を始めた製品から順にダウンロードできます。開けない場合は、まだ配信していないか、そのパスでは見られない製品です。
