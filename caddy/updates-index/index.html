ダウンロード

自作の Windows 向けアプリのインストーラーです。各製品のページで最新版を入手できます。

  • EddiePDF オフラインで動く多機能 PDF 編集ソフト ダウンロードページ
  • GUNYUPDF 書籍スキャン PDF の傾き・湾曲・影を補正するアプリ ダウンロードページ
  • ALLOCR 日本語文書をクラウドに送らずにテキスト化する OCR アプリ ダウンロードページ
  • Transinglater オフラインで動く日英翻訳ソフト（モデル込みのフル版は約 4.5GB） ダウンロードページ
  • IshikawADE やりたいことを開発タスクに整理し、計画と PR 本文案をつくるアプリ ダウンロードページ
  • DCS Mission Studio公開 DCS のミッション（.miz）を、原本を残して編集するツール 配布ページ

パスについて

  • DCS Mission Studio 以外のページを開くと、ブラウザが ID とパスワード（パス）を尋ねます。パスは配布元から受け取ったものを入力してください。
  • 製品ごとのパスはその製品のページだけ、開発協力者用のパス（ID が dev- で始まるもの）はすべての製品のページで使えます。
  • 入れたあとの更新はアプリの［更新を確認...］からできます。アプリでも同じパスを一度入力します。
  • 配信を始めた製品から順に開けます。開けない製品は、まだ配信していないか、そのパスでは見られない製品です。
