IshikawADE試作版

「やりたいこと」を開発のタスクに整理し、進め方と担当 AI を決めて、実行前の計画と PR 本文案をつくるアプリです。

ダウンロードページへ

ダウンロードページを開くとパス（ID とパスワード）を尋ねられます。パスは配布元から受け取ってください。

できること

  • 依頼文から「やること」を作り、目的・利用者・最初の版の範囲・完成条件・対象外を整理する
  • 内容を確認すると、要件の初稿と工程の流れ（共通仕様 → 機能ごとの工程 → 統合検証 → レビュー・人の確認）ができる
  • 工程を直列・並列・自動のどれで進めるかを選び、同時に進められる工程を確かめる
  • 「考える」「つくる」「確かめる」の工程ごとに担当 AI を記録する
  • 計画を確認して、PR 本文案を Markdown で保存する
  • 任意で、AI と対話しながら依頼を整理する（接続の設定が必要。送る内容は毎回確認してから送ります）

まだできないこと

  • 開発工程の実行、Git の操作、AI によるコードレビュー、GitHub への PR の作成
  • 担当 AI への接続の確認や費用の見積もり（担当 AI の設定は記録だけです）
  • 計画のバックアップと復元、端末間の同期

動作環境と配布の形

OSWindows（64 ビット）。動作を確かめているのは Windows 11 です
配布の形インストーラー（約 106MB）

更新のしかた

入れたあとは、サイドバーのいちばん下にある［更新を確認...］から新しい版に更新できます。初回だけ同じパスを入力します。更新情報は配布元の電子署名を確かめてから使います。
