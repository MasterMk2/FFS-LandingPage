Transinglater

文章を PC の中だけで翻訳する、日本語と英語の翻訳ソフトです。翻訳する文章を外に送りません。

ダウンロードページへ

ダウンロードページを開くとパス（ID とパスワード）を尋ねられます。パスは配布元から受け取ってください。

できること

  • 日本語 → 英語、英語 → 日本語の翻訳。翻訳はすべてこの PC の中で行います
  • テキストファイル（UTF-8 / Shift_JIS を自動で判別）と、文字の情報を持つ PDF を翻訳できます
  • ドラッグ＆ドロップで読み込み、原文と訳文を並べて表示、進み具合の表示
  • 翻訳エンジンを選べます: 高品質（MADLAD-400-3B）と軽量（OPUS-MT / FuguMT）
  • NVIDIA の GPU があれば、それを使って速く翻訳します（無くても動きます）

動作環境と配布の形

OSWindows（64 ビット）
GPU任意。NVIDIA の GPU（CUDA）があれば使います
配布の形フル版インストーラー（翻訳モデル込み、合計約 4.5GB）。インストーラー本体と、分割されたデータのファイル（.bin）をすべて同じフォルダーに置いてから、インストーラー本体を実行してください
通信使うのは、利用者が更新を確認したとき（または設定で有効にした起動時の確認）だけです

更新のしかた

入れたあとは、ヘルプの［更新を確認...］から新しい版に更新できます。更新ではモデルを含まない更新用のファイル（約 1.6GB）だけを取得し、入っているモデルと設定はそのまま残ります。初回だけ同じパスを入力します。更新情報は配布元の電子署名を確かめてから使います。
